# Projeto de leilões
Sistema tem foco em informatização de rotinas, com um sistema de 2 telas(Java, projeto: LeiloesTDSat) e banco de dados(MySQL, nome:uc11).
Java possuindo as classes:
ProdutosDAO.java
ProdutosDTA.java
cadastroVIEW.java
conectaDAO.java
listagemVIEW.java.
MySQL possui as tables:
produtos(PRIMARY KEY id, nome, valor, status).
